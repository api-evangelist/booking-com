# Superseded generated specifications

Every file in this directory was **generated from Booking.com's documentation** by an earlier
API Evangelist pass, not published by Booking.com. They were the six `_original/` scaffolds and the
24 tag-split specs refined from them.

On 2026-09-17 they were superseded by **20 real, provider-authored OpenAPI descriptions** retrieved
from Booking.com's own documentation MCP server (`https://developers.booking.com/mcp`,
`getFullApiDescription`) and written to `openapi/`. Those carry 210 operations across the Demand,
metasearch Connect, Status and Connectivity programmes.

Nothing here is wired into `apis.yml` and nothing here should be treated as a source of truth. It is
kept only so the earlier profile can be audited.
